# Отчёт: коммит 8 — корпуса машин не рендерились (дефект 17)

Коммит: «Fix machine bodies not rendered» (ветка `stage-2a`).

## Скилы (реально прочитанные в этом сеансе)

- Новых скилов для этой задачи не читалось (точечный фикс рендера построек в нашем three.js-коде; правило router — без pivota перечтение не требуется). В рамках сеанса уже прочитаны: **router**, **create-game-assets**, **threejs-materials-lighting**. Из применённого здесь: create-game-assets — «validate in context» (скрин поставленных машин из живой сцены после фикса), threejs-materials-lighting — материалы мешей остаются проектными (m.beam/iron/steel и т.д.), ничего нового не вводилось.

## Что сделано

- **`rakeModel` и `generatorModel` (`src/world/buildings.ts`)** — в конец обеих функций добавлен `kit.place(new THREE.Group(), () => {}, 0, 0)` (тот же паттерн, что у пояса лент в `rebuild`, строка ~137: коллайдеры регистрирует rules-слой). Теперь merged-геометрия корпуса (рама/стальные части/железный короб у граблей; короб/крышка/красный люк/ножки у генератора) реально становится мешами вместе с уже стоявшими head/tines/chimney. Функции экспортированы для headless-проверок.
- **`makeGhost`** — та же упущение исправлено опосредованно: призрак собирается из тех же `rakeModel`/`generatorModel`, теперь несёт полный корпус. Попутно прокси-материал призрака сделан по-ключевым (`ghostOk.clone()` на слот вместо одного материала на всё) — иначе все kit-материалы сливались в один меш и структура призрака не совпадала с моделью. Визуально идентично: `setValid` по-прежнему заменяет материалы обходом.
- **`beltSegment`** — упущения нет: сегменты пишут в общий kit, который размещается в `BuildingViews.rebuild` (строка ~137). Проверено, изменений не требует.

## Тесты (`src/world/buildings.test.ts`, новые, 4)

1. `rakeModel`: мешей ≥ числа kit-материалов (beam/iron/steel = 3; фактически 3 merged + голова + 6 зубьев = 10), Box3 ≥ 0.9×0.9 м в плане и ≥ 0.8 м высотой (1.1 × 1.17 × 0.99).
2. `generatorModel`: аналогично (boards/iron/red = 3; фактически 4: 3 merged + труба), Box3 1.3 × 1.3 × 2.35.
3. `BuildingViews.raycast` сверху центра каждой постройки возвращает её ref с dist > 0 (грабли и генератор отдельно).
4. `makeGhost('rake')` и `makeGhost('generator')` несут столько же мешей, сколько построенные модели (10 и 4).

Красный до фикса подтверждён живой сценой в browser-check (записан в commit-7.md): луч сквозь центр корпуса граблей не попадал ни во что, таргет ловился только по голове.
