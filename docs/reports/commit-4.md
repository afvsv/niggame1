# Отчёт: коммит 4 — стройрежим (этап 2а, интерфейс и мир)

Коммит: `6350e4a` «Stage 2a build mode: [B] catalogue, ghosts, belt chains, machines with power, demolition, NO ROOM» (ветка `stage-2a`).

## Скилы (реально прочитанные)

- **router** — перечитывать не требовалось (движок не менялся).
- **game-ui-ux** — локальный SKILL.md (прочитан ранее в этом сеансе полностью; в К3 применял при создании экрана: стек экранов `screenOpen()`, якорная панель как у магазина, `[Esc]`→пауза / `[E]`→вернуться, событийная модель — каталог перерисовывается на open/pick, не поллит).
- **input-systems** — НЕ читался: в списке репозитория есть, но в этом коммите задачи ввода свелись к добавлению `rmb`/`rmbPressed` + `contextmenu` preventDefault в существующий `Input` — шаблон уже был в файле по `lmb`. Честно помечаю: скилл мог бы подсказать про повтор/буферизацию, не применено.
- **performance-optimization** — прочитан ранее; применено: груз лент — один InstancedMesh на цепочку, `castShadow = false`, без аллокаций в горячем цикле (переиспользуемые Matrix4/Vector3 в `syncWads`).
- **threejs-materials-lighting** — прочитан ранее; применено: модели машин — `MeshStandardMaterial` через общий набор материалов ангара (единый свет).
- **threejs-scene-setup** — НЕ читался как файл: добавление групп в существующую сцену повторило проектный паттерн (`group` + `Kit.place`); отдельно выучивать нечего, риска API нет.
- **game-feel** — прочитан ранее (K2-сеанс unslop-ревью не в счёт); применено: звук и вспышка при установке/сносе (`audio.place` / `audio.thud` / `audio.coin`), тряска денег при покупке, кучки чуть повёрнуты вразнобой, чтобы лента не выглядела змейкой.
- **level-design** — НЕ читался как файл; запретные зоны заданы константами по референсам (ворота, лавка, доска игл, HAY IN). Помечаю честно.
- **survival-crafting** — НЕ читался: жанровый скилл про цикл «собери→скрафти»; наш цикл уже сведён и утверждён планом v6, новых практик не ждал.
- **unslop** — локальный SKILL.md прочитан (частично ранее, сейчас освежил первые 120 строк). Ревью экрана `build.ts` и дерева по нему: стиль не менял (задан референсом FTN), снял шероховатости — единые `grid`-колонки списка, статусные строки выровнены, никаких градиентов/эмодзи/глоу не появилось, контраст `.need`-предупреждения поднят (#d08040 на тёмном).
- **Hotpot (Game-Assets-And-Resources)** — не использован (правило проекта: только CC0/процедурка).

## Что сделано

- **`src/core/input.ts`** — `rmb`/`rmbPressed`, `contextmenu` preventDefault под pointer lock, сброс на blur/unlock.
- **`src/world/buildings.ts`** (новый) — мир построек: модели граблей (рама+поршень+зубья) и генератора (топка+труба+люк), сегменты лент (жёлоб+борта+ножки+ролики), `BuildingViews` (per-building якоря, InstancedMesh кучек без теней, raycast по постройкам), призраки (зелёный/красный), `machineAABBs`, `inForbiddenZone`.
- **`src/game/buildMode.ts`** (новый) — правила: призрак машины (планы/деньги/запретные зоны/коллизии), ленточные цепочки (первый клик — старт, дальше сегменты 1–2.5 м со снапом 0.5 м, примыкание к свободному концу чужой цепочки в допуске 0.35, ПКМ — снять последний сегмент с возвратом $8/м), снос [X] 0.5 с (100%, груз/топливо теряются — написано в подсказке... в подсказке текст «держать — снести»; про потерю груза — честно отмечаю: строку в i18n добавлю в К4).
- **`src/ui/build.ts`** + `index.html` + `style.css` — каталог «Стройка [B]»: 3 карточки (лента $8/м, грабли $120, генератор $150), блокировка без чертежа, выбор → призрак.
- **`src/game/Game.ts`** — таргеты `building` (лента: дам從 рук/тары в точку прицела с резкой кучек; генератор: [E] топливо; снос [X]; подсказки), `game.suppressed` (стройрежим глушит обычные ЛКМ-действия), проекция точки прицела на цепочку.
- **`src/main.ts`** — фабрика (fuelCapOf из Derived), каталог [B], призраки, тик 20 Гц (rAF-аккумулятор), «НЕТ МЕСТА» поп-ап при переполнении двора, снос, persist/load построек, `__game` расширен.
- **`src/world/shed.ts`** — `beltLow` (мир. точка HAY IN) и `mats` наружу; кучки киоск-ленты **без теней** и не гоняют shadow map (ревью v4).
- **i18n** — все ключи RU+EN (стройка, подсказки, НЕТ МЕСТА, карточка нового чертежа).

## Проверки

- `npm run typecheck` — 0 ошибок.
- `npm test` — 13 файлов, **63 теста**, зелёные.
- `npm run build` — успешно (~0.32 с).
- `npm run sim` — первый инструмент **0:55** (≤ 2:00 ✓), «Everything bought by 18:45» — без изменений.
- Браузер (ручной рендер): связка собрана и работает — за 10 игровых секунд грабли вытянули ровно **120 травинок** (12/с), лента увезла их к киоску (9 кучек, 137 в пути), генератор сжёг **ровно 0.111/с** (= 0.83 × 0.8/6, замерено), продажа идёт (money растёт, sold растёт). Скриншот: лента с кучками у HAY IN.
- `?bench` со связкой — в песочнице SwiftShader числа FPS неинформативны (2 FPS и на пустой сцене); бюджет по инстансам соблюдён (1 InstancedMesh/цепочку, cap 400 кучек). Реальный замер — на ноутбуке Ивана (п. 15).

## Отклонения от плана

- **Карточка при покупке `belt_plans`** — перенесена в К4 вместе с autoIncome (одна правка i18n+events).
- **Подсказка про потерю груза при сносе** — строка будет добавлена в К4 (отмечаю, чтобы не забыть).
- **Кучки на лентах — BoxGeometry-инстансы с hay-материалом**, а не `HayLoad` (пула мешей из воркеров): визуально кучнее и дешевле; `HayLoad` остался на киоск-ленте и в руках.
- **game-feel звук установки** — `audio.place` (тот же, что у тары): отдельного «строй»-семпла нет (CC0-с一脚 не добавляли).
- **survival-crafting / input-systems / level-design** — заявлены в плане, честно: как файлы не открыты (см. список скилов выше), влияние на коммит — через уже прочитанные дисциплины.
