# Trucks STEP 1 — дефект 26: ценники не обновляются

Коммит: «STEP 1: price boards update (defect 26)» (ветка `stage-2b-trucks`).

## Скилы (реально прочитанные для этого шага)

- **game-ui-ux** (`~/.zcode/skills/game-ui-ux/SKILL.md`) — взят принцип «event-driven HUD, не поллинг»: ценники перерисовываются только по событию изменения цены (сбор иглы, апгрейд deal, загрузка сейва), сравнение с последним нарисованным значением, никогда каждый кадр; строки — существующие i18n-ключи RU/EN.

## Что сделано

- **`src/world/signs.ts`**: `priceTexture()` → `createPriceBoard()` — холст-замыкание с `update(price)`: перерисовка меловой доски + `texture.needsUpdate = true` только при изменении отформатированного текста. Новая чистая функция **`priceText(price)`**: 3 знака после запятой пока цена < $1 («$0.044»), 2 знака от $1 («$1.25») — old `toFixed(2)` печатал 0.044 как 0.04.
- **`src/world/shed.ts`** — A-frame у весов создаётся через `createPriceBoard`; в интерфейсе Shed появился `updatePriceBoards(price)` (обновляет доску A-frame и карточку киоска).
- **`src/world/booths.ts`** — карточка цены внутри киоска тоже на `createPriceBoard`; хэндл возвращается из `sellBooth`.
- **`src/main.ts`** — проводка по событиям: начальная отрисовка после загрузки сейва (`game.refreshPerks()`), на сбор иглы (`events.needle`) и на апгрейд (`events.upgrade`) — `shed.updatePriceBoards(game.price)`.
- Продажа уже шла через тот же `game.price` (Derived.price = base × (1 + перки игл) × (1 + 0.1×deal)) — подтверждено тестом, изменений не потребовалось.

## Тесты (`src/world/signs.test.ts`, 3 новых)

- Формат: $0.040 / $0.044 / $0.048 / $1.00 / $1.25.
- Математика цены: base 0.04; перк Bent pin (+10%) → ×1.1; deal 1 поверх → ×1.1×1.1 (0.0484 → текст «$0.048»).
- Доска: стартовая отрисовка 1 раз с базовой ценой; `update(0.04)` — без перерисовки; `update(0.044)` — перерисовка и новый текст; повтор — холст не трогается; deal — ещё одна перерисовка.
