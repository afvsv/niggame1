# План: прототип (этап 1)

Цель: 30+ минут игры «копай → продавай → улучшайся → ищи иглы», 60 FPS на среднем ноутбуке.
Дизайн: `2026-11-05-game-design.md`. Все числа — в `src/data/balance.ts`.

Проверка каждой задачи: `npm run typecheck && npm test && npm run build`, затем ручной тест в браузере.

## Сделано
- [x] **1. Каркас.** Vite + TS + Three.js, `index.html`, стили, `base: './'` для CrazyGames.
- [x] **2. Стог.** `HayGrid` (ячейки 0.2 м, травинки в ячейке), генерация купола с шумом,
      меш по чанкам 16³ с отсечением граней и AO, процедурная текстура сена. Тесты: `grid.test.ts`.
- [x] **3. Игрок.** От первого лица, WASD/Shift/Space, коллизии с вокселями и коробками, подъём на ступеньку.
- [x] **4. Копание и продажа.** Рейкаст по сетке, ЛКМ берёт травинки (зажатие = повтор), частицы, звук;
      прилавок продаёт всё, что в руках. HUD: деньги, «осталось сена», «в руках N / cap», подсказки.
- [x] **5. Сохранения.** localStorage, сетка в RLE+base64, автосейв каждые 15 с, `?reset` и кнопка сброса.
