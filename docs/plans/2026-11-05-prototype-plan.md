# План: прототип (этап 1)

Цель: 30+ минут игры «копай → продавай → улучшайся → ищи иглы», 60 FPS на среднем ноутбуке.
Дизайн: `2026-11-05-game-design.md`. Все числа — в `src/data/balance.ts`.

Проверка каждой задачи: `npm run typecheck && npm test && npm run build`, затем ручной тест в браузере.

      Стог — гладкая поверхность (surface nets) с AO и торчащими соломинками вместо кубиков.
      Небо с облаками и солнцем, IBL от неба, тени PCF (пересчёт только при изменении стога), туман, виньетка.
      Красный амбар с каркасом, щелями между досками, дырами в крыше и лучами света с пылью; тюки.
      Снаружи луг с качающейся травой, холмы, деревья, забор, рулоны. Частицы — 3D-соломинки, падают и лежат.
      Адаптивное разрешение (отключается `?fixedres`).

## Правило: визуальная планка
- До механик — референсы (скрины оригинала, примеры) и один «красивый уголок» на целевом уровне.
- Базовый набор рендера с первого дня: sRGB + ACES, PBR с normal/roughness, тени, небо + IBL, туман, AO,
  текстуры ≥ 1024 на главном объекте, без плоских цветов. Логика (сетка) не диктует вид (меш).
- На каждом этапе — скриншоты с фиксированных точек камеры рядом с референсами. Заглушки помечаем явно.
