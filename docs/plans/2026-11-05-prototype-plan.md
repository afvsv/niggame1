# План: прототип (этап 1)

Цель: 30+ минут игры «копай → продавай → улучшайся → ищи иглы», 60 FPS на среднем ноутбуке.
Дизайн: `2026-11-05-game-design.md`. Все числа — в `src/data/balance.ts`.

Проверка каждой задачи: `npm run typecheck && npm test && npm run build`, затем ручной тест в браузере.

## Сделано
- [x] **1. Каркас.** Vite + TS + Three.js, `index.html`, стили, `base: './'` для CrazyGames.
- [x] **2. Стог.** `HayGrid` (ячейки 0.2 м, травинки в ячейке), генерация купола с шумом,
      меш по чанкам 16³ с отсечением граней и AO, процедурная текстура сена. Тесты: `grid.test.ts`.
- [x] **3. Игрок.** От первого лица, WASD/Shift/Space, коллизии с вокселями и коробками, подъём на ступеньку.
- [x] **4. Копание и продажа.** Рейкаст по сетке, ЛКМ берёт травинки (зажатие = повтор), частицы, звук;
      прилавок продаёт всё, что в руках. HUD: деньги, «осталось сена», «в руках N / cap», подсказки.
- [x] **5. Сохранения.** localStorage, сетка в RLE+base64, автосейв каждые 15 с, `?reset` и кнопка сброса.
- [x] **6. Хотбар и инструменты.** Слоты 1–9 и колесо мыши, иконки рендерятся из 3D-моделей.
      Инструмент = `grab`, `cooldown`, `radiusCells`; ёмкость = лучшая тара (руки 10, ведро 60, тачка 300).
      Инструмент в руке — отдельный проход рендера (не проваливается в сено): взмах, покачивание при ходьбе,
      инерция от мыши, смена с опусканием. Файлы: `src/data/tools.ts`, `src/game/Inventory.ts`, `src/tools/*`, `src/ui/hotbar.ts`.
- [x] **7. Магазин.** Доска «Снабжение» у входа (ЛКМ/E), список: иконка, описание, ценник-бумажка,
      «Купить» / «Есть» / «Сначала: X» / «Не хватает $N». Esc → пауза, E/«Закрыть» → обратно в игру.
      Фидбэк: звук покупки, «−$», вспышка слота; продажа — звон, «+$», счётчик денег «докручивается».
      Файл: `src/ui/shop.ts`.
- [x] **7a. Стиль ближе к оригиналу.** Почти чёрные панели, тонкие золотые/зелёные рамки, заголовки жёлтым
      капсом, цены зелёным, «Куплено» золотом; шрифт Roboto Condensed (DIN-подобный, есть кириллица).
      Руки не рисуются — видно только пучок соломы, который растёт с грузом; на инструментах тоже лежит сено.
      Модели инструментов: сужающиеся черенки с текстурой дерева, изогнутые лезвия и зубья, металл с отражениями.
      На дворе: вывеска «Продать сено» и меловая доска с ценой за травинку.
