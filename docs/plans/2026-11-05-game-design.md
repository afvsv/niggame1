# Дизайн: «Иголка в стоге» (рабочее название)

Статус: черновик v1 · Платформа: CrazyGames (десктоп-браузер, клавиатура + мышь)

## 1. Суть
Игрок от первого лица разбирает огромный стог сена в ангаре, продаёт сено и ищет иглы.
Иглы дают постоянные бонусы. Деньги идут на инструменты, улучшения и автоматизацию,
пока ручной труд не превращается в фабрику по переработке сена.

Цикл: копать → нести → продать → улучшить → копать быстрее → найти иглу → автоматизировать → контракт → новый груз.

Цели по времени: первый инструмент за 1–2 мин, первая автоматизация за 20–30 мин,
прототип ≈ 30–60 мин игры, полная игра ≈ 8–12 ч.

## 2. Технологии
- Vite + TypeScript + Three.js (WebGL2). Без физического движка: стог воксельный, коллизии считаем сами.
- UI: Preact поверх канваса (HUD, магазин, дерево улучшений, доска контрактов).
- Звук: WebAudio, звуки CC0 (Kenney, freesound CC0) + простая процедурная генерация.
- Модели: low-poly, генерируются кодом или CC0-паки (Kenney). Без чужих ассетов.
- Сохранения: localStorage, позже CrazyGames SDK Data. Локализация RU/EN с первого дня.
- Все цифры баланса — в конфигах (`src/data/*.ts`), не в коде систем.

## 3. Ключевые системы
### 3.1 Стог (самое рискованное)
- Воксельная сетка, ячейка 0.2 м, в каждой ячейке число травинок (0–N).
- Рендер: чанки 16³ с greedy-мешингом + шейдер с шумом и «ворсом» на поверхности,
  рядом с игроком — инстансы травинок для вида. Перестраиваем только изменённые чанки.
- Копание: инструмент снимает X травинок из ячеек в зоне перед камерой.
- Сохранение стога: изменённые чанки, сжатые RLE.
- Бюджет: 60 FPS на встроенной видеокарте, меньше 300 draw calls.

### 3.2 Игрок и инструменты
- Контроллер от первого лица: WASD, прыжок, бег, выносливость. Коллизия капсулы с вокселями и коробками.
- Хотбар: руки, лопатки, вилы, ведро, тачка, метла, металлоискатель, пылесос.
- Инструмент = «сколько берёт за раз» / «сколько вмещает» / «время цикла». Q — бросить, F — швырнуть, E — взять/высыпать.
- Рассыпанное сено: кучки-инстансы на полу (метла сгребает, пылесос всасывает).

### 3.3 Иглы
- 24 иглы в 4 ряда по 6 (свои названия и модели). Шанс 1:2 … 1:48 — это шанс, что игла есть в грузе.
- При генерации груза иглы кладутся в случайные ячейки (сид груза). Находятся при раскопке ячейки.
- Шкаф для игл: каждая игла даёт постоянный бонус (+% к ёмкости, к скорости, к цене…).
- Металлоискатель: частота писка зависит от расстояния, сено глушит (луч через сетку).

### 3.4 Экономика и улучшения
- Деньги, продажа на прилавке (цена за травинку × бонусы).
- Магазин: инструменты разблокируются узлами дерева.
- Дерево улучшений: ветки «ручной труд», «фитнес», «продажа», «стройка», «линии сена», «энергия», «переработка».
- Цена уровня: `base × growth^level`, эффект линейный или процентный. Баланс считаем скриптом-симуляцией.

### 3.5 Автоматизация (этап 2)
- Сетка строительства 0.5 м, призрак, поворот, снос с возвратом 100% стоимости.
- Фабрика тикает фиксированно 20 раз в секунду отдельно от рендера.
- Конвейеры: предметы — позиции вдоль сегмента, рисуются инстансами. Манипуляторы снимают сено со стога.
- Машины: рецепт (вход → выход), буфер, требуемая мощность; при нехватке энергии скорость падает пропорционально.
- Цепочка: сено → пресс → тюки; сено + вода → мешалка → плиты массы → бумажный цех → рулоны.

### 3.6 Цели
- Контракты: 7 по порядку («20 тюков», «10 рулонов»…), грузовик, награда, открытие узлов дерева.
- Грузы: новый стог открывается за N видов игл в шкафу или за деньги.
- Распродажа: снести все постройки за деньги, сохранив деньги, иглы и прогресс.

## 4. Прототип (этап 1): что входит
1. Ангар + двор, контроллер игрока.
2. Стог 12×12×8 м, копание руками, HUD «осталось сена».
3. Инструменты: руки, игрушечная лопатка, лопата, ведро, тачка.
4. Прилавок, деньги, магазин.
5. Дерево улучшений v1 (~15 узлов).
6. Иглы: 6 штук, шкаф, бонусы, металлоискатель.
7. Сохранение, настройки (чувствительность мыши, громкость), RU/EN.

Критерий готовности: можно 30+ минут играть без багов, 60 FPS на среднем ноутбуке.

## 5. Структура кода
```
src/
  main.ts            точка входа, игровой цикл
  core/              время, события, сохранения, i18n, ввод
  world/             ангар, двор, освещение
  haystack/          сетка, чанки, мешер, копание, иглы в стоге
  player/            контроллер, камера, хотбар
  tools/             инструменты и их логика
  economy/           деньги, прилавок, магазин, улучшения
  factory/           (этап 2) стройка, конвейеры, машины, энергия
  ui/                Preact-компоненты
  data/              конфиги: tools, upgrades, needles, machines, contracts
  audio/
tools/sim/           скрипт симуляции баланса (node)
```

## 6. Риски
- Производительность стога → прототип стога делаем первым и меряем FPS.
- «Ощущение» копания → много обратной связи: частицы, звук, тряска камеры, цифры «+$».
- Pointer lock в iframe CrazyGames → проверяем на их тестовой странице (QA tool) рано.
- Размер сохранения стога → RLE по чанкам, проверяем на полном стоге.
