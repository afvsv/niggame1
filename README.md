# Иголка в стоге (рабочее название)

Браузерная 3D-игра для CrazyGames: разбери стог сена, найди иглы, автоматизируй ферму.

Стек: Vite + TypeScript + Three.js.

## Запуск

```bash
npm install
npm run dev
```

Открой адрес, который покажет Vite (обычно http://localhost:5173).
